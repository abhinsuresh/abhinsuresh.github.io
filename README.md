# Abhin Suresh — personal website

Static, responsive personal website for GitHub Pages. Content is based on the supplied CV. No build step, dependencies, or JavaScript are required.

## Preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## GitHub Pages

In the `abhinsuresh/abhinsuresh.github.io` repository, choose **Settings → Pages → Deploy from a branch**, then select the branch containing this site and `/ (root)`. The `.nojekyll` file makes GitHub serve these files directly.

## Update content

Edit the HTML pages, `assets/style.css`, and `assets/cv.pdf`. The two supplied portraits are in `assets/images/`. Legacy about, projects, publications, teaching, and talks URLs redirect to their corresponding pages.
